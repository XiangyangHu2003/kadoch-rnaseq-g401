Reproducible bulk RNA-seq analysis of SMARCB1/BAF47 re-expression in G401 malignant rhabdoid tumor cells

1. Background

SMARCB1/BAF47 is a core component of the SWI/SNF (BAF) chromatin remodeling complex, and its disruption is strongly associated with tumor development in multiple cancer types. In this project, I used public bulk RNA-seq data to analyze transcriptional changes following SMARCB1/BAF47 re-expression in G401 malignant rhabdoid tumor cells. The overall goal is to identify genes and biological programs altered after BAF47 restoration.

2. Objective

The main objective of this project is to compare Empty and BAF47 re-expression samples and address the following questions:

  1. Which genes show significant expression changes after SMARCB1/BAF47 re-expression?
  2. Does BAF47 re-expression reshape the overall transcriptional program of tumor cells?
  3. Can a standard and reproducible RNA-seq workflow be built from public data to support downstream statistical analysis and biological interpretation?

3. Dataset and Samples

This analysis currently uses four G401 Day 3 RNA-seq samples:

  • G401_Empty_Day3_A
  • G401_Empty_Day3_B
  • G401_BAF47_Day3_A
  • G401_BAF47_Day3_B

Each raw sample file contains gene-level read count information. The four sample-level files were merged by GeneSymbol to create a unified count matrix for downstream DESeq2 analysis.

4. Data Preprocessing

4.1 Count matrix construction

The raw sample files did not contain column headers, so column names were assigned manually after import. The two key columns extracted from each file were:

  • GeneSymbol
  • Read.Count

For each sample, the Read.Count column was renamed using the corresponding sample ID, and all four samples were merged by GeneSymbol to generate a single count_matrix.csv file.

4.2 Metadata preparation

A sample metadata table (metadata.csv) was created with the following fields:

  • condition
  • timepoint
  • replicate

The metadata rows were reordered to match the column order of the count matrix exactly, ensuring that sample annotations were correctly aligned with expression counts.

4.3 DESeq2 object construction

The count matrix, metadata table, and the design formula ~ condition were combined into a DESeq2 dataset object using DESeqDataSetFromMatrix(). Before downstream analysis, low-count genes were filtered out, retaining only genes with a total count greater than 10 across all samples.

5.2 PCA analysis

Before PCA, count data were transformed using variance stabilizing transformation (vst) to reduce heteroscedasticity and the dominance of highly expressed genes. PCA was then performed on the transformed data to evaluate global sample structure.

The purpose of PCA was to assess:

  • whether replicate samples cluster together,
  • whether Empty and BAF47 samples show separation at the transcriptome level.

6. Differential Expression Analysis

After preprocessing and QC, differential expression analysis was performed using DESeq2 with the following contrast:

  • BAF47 vs Empty

Two result tables were generated:

  • results/tables/deseq2_results_all.csv: all tested genes
  • results/tables/deseq2_results_sig.csv: significantly differentially expressed genes

Significant genes were defined using the following thresholds:

  • adjusted p-value (padj) < 0.05
  • absolute log2 fold change > 1

This means that selected genes are not only statistically significant but also show at least an approximately two-fold expression change.

Current status:

  • DESeq2 analysis was completed successfully.
